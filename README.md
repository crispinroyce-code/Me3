# ME3 Café & Pastry Shop · Cape Coast

A mobile-friendly digital business card for ME3 Café & Pastry Shop, above SonTurk Supermarket, Kakumdu, Cape Coast, Ghana.

It has:
- **Home**: today's special, open/closed status, opening hours, contact details
- **Menu**: searchable, with a WhatsApp order tray
- **Photos**: gallery with lightbox
- **Reviews**: Facebook reviews
- **Cakes & Catering**: cake pre-order form, catering and class enquiries via WhatsApp, a QR code for the card

## Files
- `index.html`: the whole card (HTML, CSS and JavaScript in one file)
- `img/`: food and shop photos

Open `index.html` in a browser to view it. To edit the menu, hours or reviews, change the `MENU`, `HOURS` and `REVIEWS` lists near the bottom of `index.html`.
